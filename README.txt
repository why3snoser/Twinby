Twinby Soft — запуск вашего приложения

В этой папке находится app (4).py — Flask-приложение с существующими
функциями управления аккаунтами VK/Twinby, регистрации анкет и ленты лайков.

Запустите из этой папки в Windows:
  py -m pip install -r ..\requirements.txt
  py "app (4).py"

Затем откройте http://127.0.0.1:5000. Основные страницы приложения:
  / — запуск онбординга для выбранного сохранённого аккаунта
  /settings — параметры анкеты
  /accounts — сохранённые аккаунты
  /swipe — лента
  /presets — пресеты

Для остановки нажмите Ctrl+C в окне командной строки.
